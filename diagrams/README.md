# Диаграммы бизнес-процессов и системы

В разделе представлены диаграммы, разработанные в рамках анализа текущих процессов и проектирования мобильного CRM-решения для работы менеджеров на выставках.

## BPMN

### 1. Текущий процесс — AS-IS

[Открыть BPMN AS-IS](bpmn-as-is.png)

Диаграмма отражает текущий порядок работы с клиентами на выставке: поиск контактной информации, ручную фиксацию данных при отсутствии интернета, последующую обработку контактов и контроль результатов руководителем отдела продаж.

### 2. Предлагаемый процесс — TO-BE

[Открыть BPMN TO-BE](bpmn-to-be.png)

Диаграмма описывает предлагаемый процесс работы с мобильной CRM, включая онлайн- и офлайн-поиск клиентов, создание карточек, добавление комментариев, локальное сохранение информации и последующую синхронизацию данных.

## UML

### 3. Диаграмма вариантов использования (Use Case Diagram)

[Открыть Use Case Diagram](use-case-diagram.png)

Отражает основные пользовательские сценарии менеджера и руководителя отдела продаж в рамках предлагаемого MVP.

### 4. Диаграмма классов (Class Diagram)

[Открыть Class Diagram](class-diagram.png)

Описывает основные сущности предлагаемой системы: клиент, клиника, комментарий, пользователь и выставка, их атрибуты, операции и взаимосвязи.

### 5. Диаграмма объектов (Object Diagram)

[Открыть Object Diagram](object-diagram.png)

Демонстрирует пример конкретного взаимодействия с клиентом на выставке с использованием экземпляров классов и условных данных.

---

**Статус:** диаграмма AS-IS описывает обследованный текущий процесс. Диаграммы TO-BE и UML отражают предлагаемые аналитические решения и не являются описанием внедрённой системы.
