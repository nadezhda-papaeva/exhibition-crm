# Диаграммы бизнес-процессов и системы

В разделе представлены диаграммы, подготовленные в рамках анализа текущих бизнес-процессов и проектирования мобильного CRM-решения для работы менеджеров на выставках.

## 1. BPMN AS и TO BE.

[[Открыть диаграммы BPMN (PDF)](BPMN%20AS%20%D0%B8%20TO%20BE.pdf)](https://github.com/nadezhda-papaeva/exhibition-crm/blob/main/diagrams/BPMN%20AS%20%D0%B8%20TO%20BE.drawio.pdf)

Документ содержит две диаграммы:

**BPMN AS-IS** — текущий процесс работы с клиентами на выставке. Отражает поиск информации о клиентах, ручную фиксацию контактов при отсутствии интернета, последующую обработку данных и участие руководителя отдела продаж.

**BPMN TO-BE** — предлагаемый процесс работы с мобильной CRM. Предусматривает онлайн- и офлайн-поиск клиентов, создание и просмотр карточек, добавление комментариев, локальное сохранение и последующую синхронизацию данных.

## 2. Диаграмма вариантов использования (Use Case Diagram)

[Открыть Use Case Diagram (Word)](Use%20Case%20Exhibition.docx)

Диаграмма отражает основные пользовательские сценарии предлагаемого мобильного приложения.

Представлены два участника:

- **Менеджер** — авторизация, поиск клиентов, просмотр карточек, создание новых контактов и добавление комментариев.
- **Руководитель отдела продаж** — авторизация, просмотр результатов выставки и проверка полноты обработки контактов.

Диаграмма позволяет определить границы функциональности системы и распределить возможности между основными пользовательскими ролями.

## 3. UML Class Diagram / Object Diagram

[Открыть диаграммы классов и объектов (PDF)](Диаграмма%20классов%20и%20объектов%20Exhibition.drawio.pdf)

Документ содержит две UML-диаграммы.

**Диаграмма классов** — описывает основные сущности предлагаемой системы: клиент, клиника, комментарий, пользователь и выставка. Отражает их атрибуты, операции и взаимосвязи.

**Диаграмма объектов** — демонстрирует на условных данных конкретный пример взаимодействия менеджера с представителем клиники на выставке, включая фиксацию результатов общения в клиентской карточке.

---

## Статус аналитической работы

BPMN AS-IS отражает обследованный текущий процесс работы с клиентами.

BPMN TO-BE, Use Case Diagram, UML Class Diagram и Object Diagram представляют предлагаемые аналитические решения.
